# 🧜‍♀️ Siren Voice

## 更新紀錄

### 2026-08

本版本修復了長時間對話後發生的記憶體耗盡（OOM）問題——也就是對話約 20 輪左右、或打開長聊天室時，Termux / 手機瀏覽器會被系統強制關閉的狀況。

**問題原因（簡單版）**

有三個地方在不知不覺中吃掉手機記憶體：

1. **每次播放都會殘留效果節點** — 每次播放語音時，音訊混音台都會建立新的特效鏈（迴音、空間音效等），而且播完後從不拆除。播放越多次，音訊引擎就越大。
2. **每次生成都重讀全部歷史** — AI 每回覆一次，外掛就把整個聊天室「所有」語音檔全部重新載入一次，反覆載入、從不釋放。
3. **打開長聊天室會爆量載入** — 進入長聊天室時，外掛會對聊天室裡「每一則訊息」各發起一次完整的語音歷史載入，等同於同時把「訊息數 × 歷史語音數」份的完整音訊塞進記憶體，連播放都還沒開始就可能當機。

**修復內容**

- 播放結束 / 停止時，完整拆除該次播放建立的音訊特效節點鏈，不再殘留（FX 節點洩漏）
- 混響所需的脈衝回應緩衝（約 1.4MB）改為快取重用，不再每次播放重新分配
- 改用輕量元資料表管理歷史清理，不再靠 `getAll()` 把所有語音 ArrayBuffer 一次載入
- 快取改為「只更新有變動的單筆記錄」，不再每次寫入就清空整份快取
- 聊天切換時釋放上一個聊天室的語音快取，避免跨聊天累積
- `getTtsHistory` 加入單飛（single-flight）去重：開啟長聊天室時所有並行查詢共享同一次載入，不再各查各的

所有語音檔案依然完整保留，播放方式、歷史語音重播與 API 呼叫邏輯完全不受影響。

**驗證方式**

更新後在瀏覽器 Console 輸入 `window.__sirenOomFix`，應回傳 `"Stage2 loaded"`，代表新版程式碼已生效。

## 專案概述

Siren Voice 是一款專為 SillyTavern 設計的沉浸式音訊擴充套件。

本擴充套件整合了文字轉語音（TTS）、背景音樂、環境音效以及音訊管理功能，透過統一介面提升角色扮演、互動敘事以及 AI 陪伴體驗。

---

## 核心功能

### 🎙️ 文字轉語音（TTS）

- 角色語音生成
- 語音播放管理
- 多語音服務支援
- ElevenLabs 相容性支援

### 🎵 音樂系統

- 背景音樂播放
- 浮動式音樂播放器
- 播放清單管理

### 🌊 環境音效系統

- 場景環境音效
- 氣氛營造與沉浸感強化
- 環境音控制管理

### 🎚️ 音訊混音器

- 獨立音量控制
- 音樂音量平衡
- 語音音量平衡
- 全域音訊設定管理

### 📚 世界書整合

- 世界書狀態偵測
- 工作流程整合
- 相容性管理

### ⚙️ 介面管理

- 統一音訊控制面板
- 多分頁導航介面
- 行動裝置友善設計
